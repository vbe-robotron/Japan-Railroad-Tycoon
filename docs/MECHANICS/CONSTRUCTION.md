# 建設・廃線メカニクス

## 1. 路線敷設の4ゲート

路線を敷設するには、以下すべてを満たす必要がある。

### Gate 1: 技術ゲート

| 技術 | 解禁年 | 効果 |
|------|--------|------|
| 馬車鉄道 | 1880 | 都市内のみ |
| 蒸気鉄道 | 1887 | 私設特許制度開始 |
| 電気軌道 | 1895 | 都市間・路面 |
| 路面電車 | 1900 | 市内交通 |
| 郊外電鉄 | 1905 | 阪急モデル |
| 地下鉄 | 1925 | 都市地下 |
| 電化（長距離） | 1930 | 幹線電化 |
| ディーゼル | 1950 | 非電化ローカル |
| 新幹線 | 1964 | 高速（国鉄/JR専用） |
| リニア | 2027 | 未来 |

**フィクション許容:** 技術者招聘で±3年前倒し可能（コスト高）。

### Gate 2: 法規ゲート

| 年 | 法規 | 効果 |
|----|------|------|
| 1887 | 私設鉄道条例 | 私鉄解禁 |
| 1892 | 鉄道敷設法 | 幹線は国主導 |
| 1900 | 私設鉄道法 | 免許制厳格化 |
| 1906 | 鉄道国有法 | 主要私鉄17社買収 |
| 1919 | 地方鉄道法 | 郊外電鉄ブーム |
| 1927 | 東京地下鉄道開業 | 地下鉄時代 |
| 1943 | 戦時買収 | 私鉄→国鉄 |
| 1949 | 日本国有鉄道法 | 国鉄発足 |
| 1987 | 国鉄分割民営化 | JR発足 |
| 2004 | 営団→メトロ | 東京メトロ発足 |

**フィクション許容:** `lobby` アクションで法改正を早める/遅らせる工作可能。

### Gate 3: 地形ゲート

```go
type Terrain struct {
    Kind         string
    BuildCost    float64
    DistanceFactor float64
    MaxSpeed     int
}
```

| 地形 | BuildCost | DistanceFactor | MaxSpeed |
|------|-----------|----------------|----------|
| plain | 1.0 | 1.1 | 130 |
| hill | 1.5 | 1.3 | 100 |
| mountain | 3.0 | 1.8 | 80 |
| river | 2.0 | 1.4 | 110 |
| urban | 2.5 | 1.15 | 100 |
| sea | 999 | 0.0 | 0 |

**敷設コスト式:**
```
Cost = BaseCostPerKm × DistanceKm × TerrainBuildCost × GaugeFactor × DoubleFactor
```
- `BaseCostPerKm`: 時代・技術による基本単価（Phase 1-7.6: 250000 円/km）
- `GaugeFactor`: 1067=1.0, 1435=1.2, 762=0.8
- `DoubleFactor`: 単線=1.0, 複線=1.7

**例:** 梅田〜宝塚（19.1km、1067mm 単線、平地）
`250000 × 19.1 ≒ 4,770,000円`（年間収入の約 0.9 倍、投資回収約 6 年）

> Phase 1-7.6 で資産回転率を史実の鉄道に近づけるため、`BaseCostPerKm` を
> 5000 → 250000（50 倍）に引き上げた。建設費が過小で投資回収が早すぎると、
> 営業係数を調整しても資金が雪だるま式に増えてしまうため。

> **Phase 1-7.7/1-7.8 の注意:** 需要のべき乗則化で旅客収入が約 1/6 に減ったため、
> 上記の投資回収約 6 年は成立しなくなった（梅田〜宝塚・開発なしで約 22 年）。
> これは史実の戦前私鉄（投資回収 10〜20 年）に照らして現実的であり、
> Phase 1-7.8 で目標を「投資回収 15〜25 年（開発なし）」に再定義した。
>
> **Phase 1-8-2.5 の再調整:** Phase 1-7.8 の開発効果（需要 最大 5 倍）は
> 強すぎ、プレイテストで営業係数が史実の 1/4（14.3〜25.0）、24 年成長が
> 62 倍となった。そこで `DevelopedDemandFactor` を 4.0 → 1.0 とし、沿線開発
> （`City.Developed`）による需要増を最大 2 倍に抑えた。開発度 1.0 で営業係数
> 約 38.7、投資回収 約 4.2 年となる。施設の基本コストは旧比 0.6 倍、収入率は
> 旧比 0.625 倍に調整した（`FacilityTable`）。詳細は `MECHANICS/ECONOMY.md` 参照。

**距離計算:**
```
Distance = Haversine(from, to) × TerrainDistanceFactor
```

### Gate 4: 経済ゲート

- 資金 ≥ 敷設コスト
- 融資枠 ≥ 借入可能額
- 株価 ≥ 増資可能額

## 2. 敷設不可の期間（史実イベント）

| 期間 | 理由 |
|------|------|
| 1941-1945 | 戦時統制、資材不足 |
| 1945-1950 | 戦後復興優先 |
| 1987-1990 | JR発足混乱 |
| 1991-2000 | バブル崩壊、融資難 |
| 2020-2022 | コロナ、設備投資凍結 |

## 3. 廃線の4ゲート

### Gate 1: 赤字継続（経済）
- 連続赤字ターン ≥ 24（=2年）
- 累積損失 ≥ 路線価値の30%

### Gate 2: 代替路線の存在
- 他社路線が並行 → 廃線しやすい
- 道路・バスあり → 廃線可能
- 完全孤立 → 廃線困難

### Gate 3: 政治圧力
- `PoliticalPressure` が閾値以下
- `ResidentsAffected` が閾値以下
- 自治体補助金があれば圧力上昇

### Gate 4: 物理的状態
- `Condition` < 0.3 → 更新 or 廃線
- 災害で `Condition` = 0 → 復旧 or 廃線

## 4. 廃線の種類

| 種類 | 主体 | 史実例 |
|------|------|--------|
| 自主廃線 | 会社判断 | 京成の一部、私鉄ローカル線 |
| 国鉄廃線 | 国鉄→JR | 特定地方交通線（1980s） |
| 戦時買収→廃線 | 政府 | 1943年買収→戦後廃止 |
| 災害廃線 | 自然 | 土砂災害、地震 |

## 5. 廃線の効果

### 直接効果
- 路線削除
- 用地売却益（地価上昇していれば利益）
- 車両・設備の償却
- 沿線の需要減少
- 政治圧力上昇
- 評判低下

### 間接効果
- 沿線住民の減少
- 他社の進出チャンス
- 自治体との関係悪化
- 株主評価（短期的には収益改善、長期的には成長鈍化）

## 6. 廃線の不可逆性

一度廃線にすると簡単には戻せない。

```go
type AbandonedLine struct {
    LineID     string
    Abandoned  Date
    Reason     string
    Restorable bool    // 5年以内なら復活可能
    RestoreCost int64  // 元の1.5倍
}
```

- 5年以内：地価上昇していれば復活可能
- 5年超：用地が売却済みで実質不可能
- 政治圧力が高いと復活しやすい

## 7. 国鉄の特殊ルール

```go
func (g *Game) CanAbandonLine(line *Line) (bool, string) {
    c := g.Companies[line.CompanyID]
    if c.IsNational {
        if line.ResidentsAffected > 10000 {
            return false, "沿線人口が多く、政治的廃線は困難"
        }
        if g.Date.Year < 1968 {
            return false, "国鉄のローカル線廃止は1968年以降"
        }
        if !line.DesignatedForClosure {
            return false, "特定地方交通線に指定されていません"
        }
    }
    return true, ""
}
```

史実: 1968年赤字83線、1980年国鉄再建法、1981-1990年特定地方交通線83線廃止。

## 8. 災害による強制廃線

```go
type DisasterEvent struct {
    Type           string   // "earthquake"|"typhoon"|"war"|"fire"
    AffectedRegion string
    DamageRate     float64  // 0.0-1.0
}
```

被災後の選択:
1. 復旧する — 資金投入、時間がかかる
2. 廃線する — 即座に損失確定、政治圧力上昇
3. 放置する — 時間経過で自然廃線（最も評判悪い）
